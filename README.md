# C# Group Assignment

A group assignment built with **Unity and C#**.

## Project Description

The goal of this project is to create a **first-person parkour game** together with a group of classmates.

The player must navigate through the level, retrieve items, and deposit them into a container within a certain time limit to earn points.

## Core Gameplay

The game should include:

- First-person player movement
- Parkour-based level traversal
- Collectible/retrievable items
- A container where collected items can be deposited
- A time limit
- A point/score system

## Grading Guidelines

### G-Pass

To receive a passing grade, the group must deliver a:

- Working game
- Playable build of the game

## Nice-to-Haves

Additional features that can improve the game include:

- **Mathematical platform movement**
  - Platforms moving according to mathematical and trigonometric patterns
  - Examples: `sin`, `cos`, `tan`, etc.

- **UI / HUD**
  - Timer
  - Score
  - Item information
  - Other useful player feedback

- **Gamepad Support**
  - Implemented using Unity's **New Input System**

- **Visuals & Game Feel**
  - Improved visuals
  - Sound effects
  - Animations
  - Particles
  - Other forms of game "juice"

## Technologies

- **Unity**
- **C#**
- Unity New Input System *(optional / nice-to-have)*

## Objective

Retrieve as many items as possible and deposit them into the container before the timer runs out.

Use movement and parkour mechanics to navigate the level efficiently and maximize your score.
